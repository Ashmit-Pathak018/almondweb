Almond is an experimental cognition research project exploring governed memory, temporal reasoning, retrieval systems, and artificial continuity.

Section 01 — The Goal

What we are building.

Most AI systems treat memory as storage. Add more tokens, retrieve semantically, discard old context. It scales poorly and forgets things that matter while retaining things that don't.

Almond explores whether memory should behave more like cognition. The project investigates persistence, forgetting, temporal reasoning, memory governance, and continuity across long conversations.

This is not a commercial product. This is an ongoing research effort. Some experiments fail. Most assumptions turn out to be wrong. That's the point.

Current Stage

Active Experimentation

T-MMU architecture stable. Temporal cognition work ongoing. Almond Lab v1 running.

What exists

Memory architecture, benchmarks, observability tooling, retrieval traces.

More than a concept. Less than a finished system.

Time commitment

Flexible — from occasional to deep.

Some contributors work a few hours a week. Some go deep. Both are useful.

Section 07 — FAQ

Questions.

Do I need AI or ML experience? ▾
No. Some roles require it — memory systems, retrieval engineering. Others don't — documentation, frontend, research summaries. Read the role descriptions carefully. If you're unsure, ask.
Can beginners contribute? ▾
Yes. The beginner-friendly tasks section lists real work that needs doing right now and doesn't require deep technical expertise. Starting small is fine — most contributors do.
Is this paid? ▾
No. Almond is a research project, not a company. There is no funding, no salary, no equity. Contributors work because they find the problem interesting.
How much time is expected? ▾
Whatever you have. Some contributors ship one thing a month. Some work weekly. There are no minimums. The project moves at the speed of interest, not obligation.
Can I contribute occasionally rather than regularly? ▾
Yes. A well-scoped one-time contribution is genuinely useful. You don't need to commit to an ongoing role.
Can I propose my own ideas? ▾
Yes, and encouraged. The project benefits from people who see problems the current team hasn't noticed. Bring ideas. The worst outcome is a conversation.
What technologies does the project use? ▾
Python for the core architecture and benchmarking. JavaScript / HTML / CSS for the frontend and Almond Lab. Vector databases for memory storage. LLM APIs for evaluation. Specifics are discussed during onboarding.
