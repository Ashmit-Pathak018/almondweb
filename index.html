Core Belief

Intelligence without
memory is imitation.

The goal is not infinite recall. The goal is meaningful persistence.

The problem

Most LLMs treat memory as a size problem. Bigger context windows. Larger vector stores. More retrieval. But quantity isn't quality — floods of weak memories pollute reasoning as much as no memory at all.

The realization

Human memory is powerful not because it's perfect — but because it's selective. It prioritizes. It forgets. It compresses. It adapts. Artificial systems rarely do any of these.

The direction

Almond explores governed memory: systems that decide what deserves attention, what should decay, and what earns permanence. Memory as a cognitive resource, not a storage problem.

Local-first sovereignty

If memory becomes truly persistent and personal, privacy becomes non-negotiable. Almond pushes toward on-device embeddings, local retrieval, and optional cloud — not the other way around.

The Architecture

Temporal Memory
Management Unit

The T-MMU treats cognition like an operating system treats RAM — with layers, eviction policies, and active governance. Click any layer to expand.

L1

Hot Cache

Immutable system rules and core identity. Never evicted.

Foundational instructions, persistent behavioral constraints, permanent cognitive rules. This layer is write-once — it defines the system's identity and cannot be overwritten by incoming context. Analogous to ROM in hardware: always present, always authoritative.
Permanent
L2

Active RAM

Live working memory injected into the LLM context. Intentionally limited.

Where active reasoning happens. Scarcity is a feature here — the system must decide what deserves attention. Governed by P_eff scores and retrieval quality thresholds. Low-scoring candidates are rejected before injection, keeping context clean.
Live
L3

Virtual Swap

Long-term persistent storage via SQLite + vector retrieval.

Episodic memory that isn't actively reasoning but can be recalled. Powered by ChromaDB vector search with hybrid semantic + P_eff reranking. Memories here decay over time unless reinforced — retrieval is selective, not exhaustive.
Persistent
L4

Archive

Compressed aging memory. The start of semantic abstraction.

Episodic details slowly collapse into generalized knowledge. This is the research frontier — the transition from "I remember X happened" to "I understand that X-type things tend to work this way." The long-term goal is not storage but transformation.

Memory Dynamics

The P_eff Formula

Effective priority score — governs which memories survive, which decay, and which earn retrieval. Not every memory deserves immortality.

P_eff = I_base × exp( −(λ / S) × Δt )
I_base
Base importance score assigned at memory creation. Reflects recency, source trust, and initial relevance.
λ (lambda)
Decay rate constant. Controls how fast a memory fades under pressure. Tunable per memory type.
S (stability)
Reinforcement score. Increases when a memory is retrieved and confirmed. Slows decay for important memories.
Δt (delta-t)
Time elapsed since last access. The longer a memory sits unretrieved, the lower its P_eff score.

Development Log

Journey so far

Almond began as a single question. Each entry below marks a meaningful shift in thinking — not just in code, but in what memory means for artificial systems.

Early 2026 · The Question
The beginning
Not a roadmap, not a pitch. A single observation: AI systems remember everything badly instead of remembering important things well. That question quietly became a research project.
Phase 01 · Architecture
T-MMU prototype established
The four-layer memory stack (L1 through L4) takes shape. Memory stops being a flat list and becomes a governed hierarchy — permanent, active, persistent, and archival layers with distinct eviction rules.
Phase 01 · Scoring
P_eff formula developed
Static memory ranking replaced with dynamic decay. The P_eff formula introduces time, reinforcement, and pressure as first-class memory signals. Not every memory deserves immortality becomes foundational philosophy.
Phase 01 · Retrieval
Hybrid retrieval implemented
Semantic flooding — where irrelevant but similar memories flood active context — proved a critical failure mode. Hybrid reranking with P_eff weighting, adaptive depth, and threshold gating dramatically improved context cleanliness.
Phase 01 · Evaluation
Unified evaluation runtime
LongMemEval integration, automated ablation pipelines, and overnight benchmark orchestration built. The project crossed from "collection of AI scripts" into recognizable research infrastructure.
Phase 02 · Now
Systems integration & stabilization
Retrieval precision continues improving. Context cleanliness, orchestration reliability, and benchmark realism all under active work. The hardest problems — contradiction handling, temporal reasoning, semantic consolidation — are ahead.
Research Frontier

Open Questions

These are not engineering problems waiting for a clever library. They are foundational questions about how artificial cognition should work over time.

Q.01
How should artificial forgetting behave?
Not all forgetting is failure. What decay curves produce useful selective attention rather than random loss?
Q.02
What makes a memory worth keeping?
Importance is dynamic. A memory irrelevant today may be critical tomorrow. How should salience be tracked over time?
Q.03
Can episodic memories become semantic knowledge?
Humans abstract experience into understanding. Can artificial systems compress specific events into generalized insight without losing what mattered?
Q.04
How should conflicting memories resolve?
When two stored beliefs contradict each other, which wins? What should a governed memory system do with conflict rather than ignoring it?
Q.05
What creates continuity of identity over time?
If memory constantly decays and updates, what makes the system consistent? What is the artificial equivalent of a stable self?
Q.06
How should long-term cognition scale under entropy?
As memory accumulates, noise grows. What architectural properties allow a system to remain coherent under long-term cognitive pressure?
