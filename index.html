Architecture — T-MMU

Memory Management Unit

Almond separates memory into layered cognitive structures. Each layer has distinct retrieval priority, decay behavior, and persistence rules.

L1

Working Memory

Immediate short-term reasoning context used during active interaction.

L2

Active Memory

Frequently accessed memories with high retrieval priority and active reinforcement.

L3

Long-Term Memory

Persistent semantic and episodic memory structures optimized for continuity.

L4

Distilled Memory

Condensed stable abstractions representing durable long-horizon cognition.

Persistence Governance — P_eff

Persistence must be earned.

Most systems assume every memory deserves equal survival. Almond assumes otherwise. P_eff attempts to model that process.

P_eff = I_base × exp( −(λ / S) × Δt )
I_base intrinsic importance at formation
λ decay rate constant
S salience — context relevance multiplier
Δt elapsed time since last reinforcement
Birthday remembered for years
P_eff = High
Random grocery list, unretrieved
P_eff = Low
Repeated project discussion
P_eff ↑ via reinforcement

Research Log

What actually happened.

Including failures. Especially failures.

2025 — Q1

Memory Accumulation Experiment

Attempted naive accumulation: store everything, retrieve semantically. Hypothesis: more context improves response quality.

Result: Failed. More memory produced worse retrieval quality. Signal-to-noise collapsed.
2025 — Q2

Persistence Layer Design

Early attempts at layered memory with retrieval ranking and decay functions. First definition of P_eff scoring.

Result: Partial. Retrieval improved. Temporal reconstruction remained unsolved.
2025 — Q3

LongMemEval Integration

Benchmark systems and retrieval diagnostics introduced. First structured evaluation of continuity behavior across sessions.

Result: Useful. Exposed systematic failures in cross-session coherence.
2026 — Q1

T-MMU Architecture

Formal separation of memory into L1/L2/L3/L4 tiers. Each layer with distinct decay, retrieval priority, and persistence rules.

Result: Ongoing. Most stable architecture iteration to date.
2026 — Q2

Almond Lab + Temporal Cognition

Internal observability platform built to inspect retrieval traces, memory tiers, and cognition flow. Current focus: chronology reconstruction.
